## ⚠️ Three things worth flagging before you run this

**CTR as the sole KPI.** CTR measures curiosity, not fit. At $45k ACV with a long cycle, a creative can win CTR by attracting clicks from people who will never buy (wrong seniority, wrong company size, wrong industry) and still "win" the test. Recommend keeping CTR as the **primary optimization metric** (since that's the decision made) but adding **landing page conversion rate** and **cost per MQL** as guardrails — if Variant B's CTR win doesn't hold up on lead quality, that's a signal to revisit, not a reason to ignore the KPI you chose.

**Single persona ("IT decision makers").** Compliance automation is rarely bought by IT alone — GRC leads, Compliance Officers, and CISOs are usually in the buying committee, sometimes as the economic buyer. If Variant B was tested only against an IT audience, scaling it to Compliance/Risk titles under the same "IT decision makers" label is an assumption, not a validated result. Brief below keeps one message as instructed, but widens the *targeting* to the adjacent titles most compliance-automation deals actually close through — flag if you want it narrowed back to IT-only.

**"Messy dashboard → clean dashboard" proof.** This is a generic SaaS trope (works for project management, analytics, anything). For a skeptical, risk-averse compliance buyer, it doesn't visually say "audit-ready" or "reduced risk" — it says "tidier UI." Recommend anchoring the same before/after structure to something compliance-specific (e.g., scattered spreadsheets/audit evidence → single audit trail, or red/flagged controls → green/passed controls) so the visual carries the category's actual value prop, not just aesthetics. Kept the generic version as an option below since that's what was specified.

## 5. Creative — Proof Concept
**Before/after graphic: messy dashboard → clean dashboard.**

Specs:
- Format: static image + matching video/motion cutdown (LinkedIn Single Image + Video ad)
- Before state: cluttered, disorganized dashboard (spreadsheets, red flags, scattered tabs)
- After state: Nuvolo's actual product UI, clean, organized, "audit-ready" framing
- Use real product screenshots for the "after" state — avoid mockups; compliance buyers discount anything that looks staged
- Aspect ratios: 1:1 (feed), 4:5 (mobile feed), 16:9 (video)
