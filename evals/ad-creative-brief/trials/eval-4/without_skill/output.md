# Brightfin — Paid Creative Brief: Format Recommendation & Deliverables

## Decisions, resolved

**1. Full UGC program in 6 business days — not viable as the launch vehicle.**
Creator sourcing alone (vetting, outreach, contracts, briefing) typically runs 1–3 weeks even with an existing creator pool. From zero creators, compressing sourcing + shoot + edit + revisions into 6 days forces a choice between missing the App Store slot or shipping unvetted, rushed content on the one placement that can't move. Since the date is fixed, the format has to be fixed to what's actually executable in-house by day 6.

**2. Dropping static permanently — rejected.**
"Statics are dead" is a slogan, not a finding — Brightfin has no test data of its own yet. Static remains the fastest, cheapest way to iterate on message/hook before committing video budget, and it's the one format the current team (1 in-house designer) can produce reliably today. Retiring it pre-emptively removes the tool best matched to both the deadline and the team's actual capacity. Recommend re-litigating this after the first UGC performance data exists — not before.

**Net call:** Static/motion carries the App Store launch. UGC becomes a second-wave program that starts now but ships later, once it's been sourced properly.

---

## Format Recommendation

**Track 1 — Launch creative (Day 0–6, in-house):**
Static and light motion graphics, produced by the in-house designer. This is the only format that can be fully controlled, iterated, and QA'd within the hard deadline — it carries the App Store feature moment.

**Track 2 — UGC program (kicks off Day 0, ships later):**
Creator sourcing and program setup start immediately, in parallel, with no dependency on the Day 6 date. Target a first UGC creative drop 3–4 weeks out, once creators are vetted, briefed, shot, and edited properly. This is a second wave, not a rescue mission for the launch date.

**Standing rule:** Static stays in the format mix as an ongoing testing lane (fast, cheap, high iteration speed for hooks/messaging) alongside UGC video (better for trust/storytelling at scale) once both have running performance data. Format allocation gets revisited by results, not by assumption.

## Deliverables

### Track 1 — App Store launch set (due Day 6)
- 6–10 static ad variants testing distinct hooks/angles (budgeting pain points, savings goals, social proof)
- Each variant cut to core paid social ratios: 1:1, 4:5, 9:16
- 2–3 light-motion variants (simple animated versions of top static concepts) if designer bandwidth allows — static is the guaranteed baseline, motion is upside
- Matching App Store product page assets: updated screenshots and promotional text aligned to the featured placement
- Copy variants (headline + primary text) per creative, for message testing independent of visual testing

### Track 2 — UGC program (kicks off now, delivers ~week 3–4)
- Creator sourcing brief and casting criteria (audience fit, aesthetic, budgeting-app credibility)
- Shortlist and outreach to 6–10 candidate creators; target 3–5 contracted
- Content brief/script framework per creator (problem → app moment → outcome), left loose enough for authentic delivery
- Usage rights and whitelisting terms secured in contracts (paid social + organic, term length defined)
- Raw footage + edited cuts per creator: one long-form (15–30s) and 2–3 short cutdowns (6–15s) per piece, in 9:16 primarily, 1:1/4:5 as needed
- Performance recap after first flight, used to decide ongoing static/UGC budget split
