## 2. Day-1 negatives for the new product-line campaign (launching Monday)

Since it has zero history, the goal is to front-load protection instead of learning it the expensive way over week one.

1. **Attach the entire Shared Negative Keyword List above to the new campaign before it goes live.** This alone is the highest-leverage move — a brand-new campaign has no learned negatives, so it needs the mature list from minute one, not after a costly first week.
2. **Add these extra guards specific to a brand-new, unproven campaign:**

```
"reviews"
"alternatives"
"vs"
"comparison"
"pricing" — *only add this if you don't want price-shopping top-of-funnel clicks; many B2B teams actually want "pricing" traffic, so leave it OUT if pricing-intent searchers are good leads for you.*
"demo" — same caveat, likely leave OUT since "demo" is often a strong buying signal.
"case study"
"api documentation"
"integration guide"
```

3. **Use exact-match negatives on single generic words that broad match will latch onto** — since the campaign has no Quality Score history yet, broad match is more likely to drift. Candidates: `[payroll]` alone is too aggressive to block, but do block `[software]`, `[app]`, `[tool]` as bare exact-match terms if you're running any broad-match keywords, since these alone shouldn't trigger a show.
4. **I don't know the exact product this new line covers** (e.g., benefits admin, time & attendance, contractor payments, global payroll) — once you tell me, I'll add category-specific negatives so it doesn't accidentally catch searches for the _other_ product line you already sell.
5. **First 7 days: check the Search Terms report daily**, not weekly — with zero history, junk shows up fast and cheap to fix now, expensive to fix after $1-2k has already burned.
