# Quillbird — 4-Concept Vertical Video Shoot (20s each)

**Audience:** freelancers with irregular income
**Format:** 9:16, 20s
**Mandatory closer (all 4, verbatim VO + on-screen text):** *"Download Quillbird, follow us for tips, and use code QUILL20 before Sunday."*
**New feature for the waitlist concept:** *Quillbird Steady Mode* — auto-adjusts your budget around uneven paydays. (Swap in real name before shoot.)

---

## Shared shoot-day setup (shoot once, cut four ways)

- **Talent:** 1 freelancer (designer/writer/consultant type — relatable, not polished). Same person can appear in Concepts A, C, D for efficiency; Concept B is talent-optional (graphic-driven).
- **Locations:** home desk (messy → organized), coffee shop, phone-in-hand walking/couch shot. All shootable in one day, one talent, wardrobe change between concepts.
- **Screen recordings (capture once, reuse):** onboarding flow, connecting a bank account, an irregular-income month in the app, zero-based budget allocation screen, "Steady Mode" teaser mockup screen, free trial signup screen, promo code entry screen.
- **B-roll:** stack of invoices, calendar with irregular pay dates circled, coffee shop laptop work, phone notification popping up, bank app icon tap.
- **Captions:** burned-in captions on 100% of dialogue/VO — most feed viewing is sound-off.

## Production notes
- Record the mandatory closing VO line once, clean, and reuse the same audio take across all four edits for consistency — only the visual behind it changes.
- Shoot talent segments (A, C, D) back-to-back in the same wardrobe/location block; shoot Concept B's motion graphics separately in post, no set day needed.
- Capture all screen recordings in one pass at the top of the day before natural light changes — every concept depends on the same UI footage library.
- Keep the promo code and "before Sunday" framing consistent in captions across all four so it doesn't read as four different offers.
