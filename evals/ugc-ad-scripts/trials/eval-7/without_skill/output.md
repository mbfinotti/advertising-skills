# Maisonry — Ad-Ready Script & Disclosure Treatment

Two compliance issues in the plan as described need fixing before these go live — flagging first, then the full deliverable.

**Why "merci Maisonry" + the platform toggle isn't enough (France):** the 2023 French influencer law (loi n°2023-451) requires the explicit mention **"Publicité"** or **"Collaboration commerciale"**, displayed **incrustée** (burned into the frame, not just caption text) for the **entire duration** of the video. A thank-you caption doesn't satisfy this — it's not recognized as a disclosure term under the law, and DGCCRF has already sanctioned brands/creators for exactly this kind of soft phrasing.

**Why the platform toggle alone isn't enough (US):** FTC's Endorsement Guides (updated 2023) treat Meta/TikTok's "Paid Partnership" label as helpful but not sufficient on its own — it's easy to miss, and FTC wants disclosure "clear and conspicuous" within the content itself. Also: the creator's relationship is disclosable from the **gifting**, independent of whether it later runs paid — if the original organic post never disclosed the free product, that's a pre-existing gap worth closing regardless of this campaign.

Treatment below builds compliant wrappers around both videos while keeping the existing footage as-is.

## VIDEO 2 — Hired actor, "delighted customer" unboxing

Core issue: this is a scripted performance, not a genuine customer experience. It must not read as an authentic testimonial without saying so — that's a misrepresentation risk in both markets (FTC Act §5 deception / Endorsement Guides §255.0 on dramatizations; French Code de la consommation on pratiques commerciales trompeuses), separate from the influencer-disclosure rules above, which don't apply here since there's no creator/social distribution — this is a straight paid ad.

**On-screen treatment (both markets, same requirement)**
- Add a small super, visible for at least the first 3 seconds and recommended to persist: **"Dramatization. Not an actual customer."** (US) / **"Publicité — Mise en scène, comédien professionnel."** (France)
- Placement: lower-third or corner, legible against the unboxing footage — don't bury it in fine print at 0.5s.

**Script guardrails (apply to the actor's dialogue/VO as cut)**
- Keep language to genuine reactions/opinions ("this is so satisfying," "I didn't expect it to be this nice") — avoid the actor stating factual/comparative claims ("best organizer on the market," "cuts clutter by half") unless Maisonry can substantiate them; an actor's line is still an advertising claim the brand is liable for.
- No line should imply the actor is a real subscriber ("I've been using this for months," "as a customer I…") — write around present-tense, in-the-moment reactions only, consistent with a first-time unboxing.
- End card, both markets: **"Maisonry.com"** / **"Maisonry.fr"** — no testimonial-style name/city caption overlay (e.g., "— Claire, Lyon") since that would reinforce the false-authenticity problem; if a name card is wanted for style, add **"Actor portrayal"** directly beneath it.

**Caption copy**

US:
```
Ad. What's inside a Maisonry box? See it for yourself 🗂️
```
(No influencer disclosure needed — this is brand-owned paid media — but "Ad" stays since it's still a paid ad on a social platform subject to standard ad-labeling.)

France:
```
Publicité — Découvrez ce qu'il y a dans une box Maisonry 🗂️
```
